## 国际网络专线服务是什么：三种形态一句话分清

国际网络专线服务，指跨越国家或地区、提供各种速率端到端数字专有带宽连接的租用服务，适合高速率、信息量大、实时性强的业务传送，比如视频会议、业务数据同步和对延迟敏感的交易系统。市面上能买到的形态主要分三类。

### IPLC：点对点的私有租用电路

IPLC（International Private Line Circuit，国际专用线路）是一条点对点的私有租用线路，把分布在不同国家的办公室、数据中心和云服务直连起来。它不经过公共互联网，只有授权用户可以访问，响应快、延迟波动小，适合视频会议、时间敏感的数据交换和关键业务应用，在银行、金融市场、内容交付和数据中心相关行业用得尤其多。

承载方式上，主流 IPLC 跑在具备自愈能力的 SDH 光纤网络上。以中国电信（欧洲）为例，其 IPLC 通过具备自我修复功能的 SDH 光纤网实现中欧站点间的端到端连接，并由两个网络运营中心进行 24/7/365 的主动监控。

### IEPL：二层以太网专线

IEPL（International Ethernet Private Line，国际以太网专线）可以理解为 IPLC 的以太网版本：一条安全的二层点对点以太网电路。它基于 SDH/MSTP 传输平台提供端到端托管带宽，使用标准以太网接口（以太网、快速以太网、千兆以太网），支持点对点或点对多点连接，带宽常见从 2 Mbps 到 1000 Mbps 可选，适合局域网扩展、WAN 互联以及高带宽、高流量应用。

两者的关系一句话说完：功能相似，IEPL 的部署成本通常更高。两个机房之间拉一条稳定电路，IPLC 就够；多地组网、设备全是以太网环境，IEPL 更顺手。

### SD-WAN：中小企业用得最多的合规方案

SD-WAN 是近几年中小企业选择最多的形态：供应商在办公现场放置 CPE 分流设备，移动端配套 VPN 客户端，跨境流量按策略走专线，其余流量照常走本地网络，通常还附带统一管理面板。部署快是它最实际的卖点，例如站擎数据宣称其企业级国际云专线一周之内开通、全程零配置，全球分支组网在控制面板上点击即可部署。

## 合规专线的真实交付形态：CPE、白名单与日志留存

很多人以为合规专线买回来就是一个“直接能上外网”的服务，实际交付形态要具体得多，也透明得多。

端到端方案的主流做法是：供应商在用户现场提供 CPE 分流设备，在移动端提供 VPN 软件，跨境链路按策略分流。为了满足合规要求，CPE 会留存并上报访问日志；有些供应商为了进一步规避风险，分流策略直接采用白名单——只分流 Office 365、Amazon 这类低风险应用，企业有额外需求需要按个案申请评估。

另一类交付更“裸”：供应商提供的是一个国内入口 IP 加一个境外出口，后续服务要自己搭建。它适合有技术能力的团队，价格通常也更低。

还有一层行业内情：跨境链路是各家供应商的核心竞争力，公开信息很少。有的供应商直接与三大运营商签约低价拿带宽，更多则从各级转售渠道采购。三大运营商一般不直接对接中小企业，这造成了层层转售的现状——层级越低越不合规，最底端就是各种中转机场。选供应商时，问清楚上游链路从哪来，比看官网宣传有用得多。

## 专线多少钱：先分清全电路和半电路

国际专线几乎没有标价，报价由两端本地段、国际段电路、带宽和路由共同决定。以中国移动国际专线业务为例，其端到端服务的计费模式分两种，签合同前必须先弄清楚你买的是哪种。

**全电路**：包含中国大陆境外电路在内，即经国际局至香港 PoP 点后，转接到其他国家 PoP 至 PoP 的全电路。资费 = 国内本地段费用 + 国际全电路费用 + 海外本地段费用。

**半电路**：只包含中国侧，资费 = 国内本地段费用 + 中国侧半电路费用。海外段电路和费用需要自行解决或另行采购。

两个容易漏算的地方：海外（含港澳台）本地段除了本地月租费，还有一次性费用，金额取决于海外端的具体落地点位；国内本地段包含本地和国内长途数字电路的月租费与一次性费用。谈判时把这些拆开问清，比只盯“每兆每月多少钱”更容易算出真实总成本。

## 常见问题

### 国际专线和普通 VPN 有什么区别？

专线的核心在于“专有”：端到端数字专有带宽，不与公共网络共享，只有授权用户可以访问，因此速度稳定、延迟波动小，也不暴露在公共互联网的风险中。普通 VPN 依然跑在公共网络上，速度和稳定性受公共网络状况影响，承载敏感业务数据时要谨慎。

### 中小企业能直接找三大运营商买专线吗？

一般不能。三大运营商通常不直接对接中小企业，专线业务多通过各级渠道落地。挑选时关键是确认供应商的上游链路来源，渠道层级越少越可靠。

### IEPL 和 IPLC 到底选哪个？

两地之间拉一条稳定、私密的线，选 IPLC；多地组网、设备以以太网为主、需要点对多点连接，选 IEPL，并把更高的部署成本算进预算。

### 专线开通要多久？

取决于形态。SD-WAN 类方案部署最快，有服务商宣称一周内开通；IPLC/IEPL 的开通周期需要向供应商确认，签约前问清交付时间。
